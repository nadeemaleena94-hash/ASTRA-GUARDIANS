
# 🚀 ASTRA GUARDIANS

### One Astronaut. One Planet. Infinite Possibilities.

ASTRA GUARDIANS is an educational space-defense game developed for the NASA Space Apps Challenge 2026, under the Space Game Design challenge.

## 🌍 About the Project

The player becomes a computer-science-skilled astronaut responsible for protecting Earth from potential space-object threats.

Players complete interactive missions involving asteroid detection, scientific analysis, and planetary defense strategies.

The project combines space science, technology, strategy, and interactive learning.

## 🎮 Game Features

- Interactive astronaut-themed game interface.
- Three planetary-defense training missions.
- Mission progression and scoring system.
- NASA Near-Earth Object data integration.
- Asteroid size, velocity, and distance information.
- Educational explanations of asteroid deflection.
- Offline training mode.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a modern web browser.
4. Allow internet access for NASA data retrieval.

For regular NASA API use, replace DEMO_KEY in script.js with your own NASA API key.

Obtain an API key:

https://api.nasa.gov/

## 🧪 Scientific Limitations

This project is an educational simulation.

Its training decisions do not represent operational asteroid-defense instructions.

NASA's potentially hazardous asteroid classification does not mean an impact is predicted.

The game focuses on near-Earth asteroids and comets rather than treating stars as incoming threats.
